# Sthira – Structural Project Workspace

Sthira is a preliminary structural decision-support and learning tool designed to make structural engineering calculations easier to understand.

## 🚀 What it does

- Describe a building using natural language
- Extract basic project information
- Visualize a conceptual structural frame
- Show the structural load path
- Perform preliminary RCC checks
- Compare "what-if" changes
- Estimate basic quantities
- Generate a preliminary structural report
- Show assumptions and calculation working

## 🏗️ Example Project

Example input:

G+5 residential building, 30 m × 20 m, in Visakhapatnam, medium soil.

The tool extracts the project information and provides preliminary calculations for learning and decision support.

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- HTML Canvas
- Responsive Web Design

## ⚠️ Important

Sthira is a preliminary learning and decision-support tool.

It is **not a construction design** and must not be used as a substitute for a licensed structural or geotechnical engineer.

All assumptions, calculations, code editions and results must be independently verified before professional use.
